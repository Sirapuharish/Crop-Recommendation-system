Crop Recommendation System

A simple machine learning project that predicts the best crop to grow based on soil nutrients and environmental conditions.
The project includes a trained ML model and a Flask-based web interface.

🚀 How to Run
1. Install dependencies
pip install -r requirements.txt

2. Start the Flask server
python app.py

3. Open the app

Go to your browser and open:

http://127.0.0.1:5000
